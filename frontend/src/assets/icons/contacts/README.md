# Иконки контактной информации

## 📁 Расположение
Эта папка содержит SVG иконки для блока "Контактная информация" в профиле.

## 🎨 Как заменить иконки

### Способ 1: Заменить SVG файлы (Рекомендуется)
1. Откройте нужный SVG файл в этой папке
2. Замените содержимое на свой SVG код
3. Сохраните файл с тем же именем
4. Иконка автоматически обновится в профиле

### Доступные файлы:
- `phone.svg` - Иконка телефона
- `email.svg` - Иконка почты
- `telegram.svg` - Иконка Telegram
- `github.svg` - Иконка GitHub
- `vk.svg` - Иконка VK
- `whatsapp.svg` - Иконка WhatsApp

### Важно:
- Сохраняйте файлы с теми же именами
- Используйте формат SVG
- Рекомендуемый размер viewBox: `0 0 20 20`
- Используйте `currentColor` для цвета, чтобы иконка наследовала цвет из CSS

## 📝 Пример замены

Откройте `phone.svg` и замените содержимое:

```svg
<svg width="20" height="20" viewBox="0 0 20 20" fill="none" xmlns="http://www.w3.org/2000/svg">
  <!-- Ваш SVG код здесь -->
  <path d="..." stroke="currentColor" strokeWidth="1.5"/>
</svg>
```

## 🔧 Где используются
Иконки используются в компоненте `Profile.jsx` в блоке "Контактная информация".
